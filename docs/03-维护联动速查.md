# 03 维护联动速查（作者维护文档）

> 本文件回答：**改了一个地方，还要动哪里才不会出问题时 FAIL 或语义不一致。**
> 与 `02-章间依赖与数据流.md` 互补：02 讲"运行时数据怎么流"，本文件讲"编辑时哪些位置要同步"。
> `scripts/verify.py` 能机械检查的部分标了 [V]；剩余需人工判断的标 [H]。

---

## 1. 改章标题/文件名

触发场景：给某章改名（如"考卷与评测集"改成"评测集与考卷"）或调整文件名。

| 需要联动的位置 | 检查方式 |
|---|---|
| 文件名 `references/NN-新主题词.md` | 手动 |
| 章正文 H1 首行 `# N 新主题词` | [V] `check_title_topic` |
| `00-全局地图.md` 对应 `## N. 新主题词（...）` | [V] `check_title_topic` + `check_map_section` |
| `SKILL.md` 路由表中的链接文本与 URL | [V] `check_links` |
| `references/` 内其他章对该章的链接（若有） | [V] `check_links` |
| `README.md` 文档结构列表的链接文字与 URL | URL 目标存在性 [V] `check_links` 兜底；文字与章名同步靠手动（README 仅被扫链接/字符，不跑章结构/主题词） |
| `scripts/verify.py` 的 `KNOWN_REF_FILES` 集合 | 手动，改了文件名必须同步 |

---

## 2. 改判点编号（增/删/重排）

触发场景：新增一个检查点、删除旧判点、或重排编号。

| 需要联动的位置 | 检查方式 |
|---|---|
| 本章判据表首列 `| N.M.K |` | 本体改动 |
| 本章"正文小节导航"（若新增了 `##` 小节） | [V] `check_toc` |
| 本章"检测注意事项"中的纯文本引用 | [H] 全文搜索旧编号 |
| 其他章引用该判点号的正文 | [V] `check_ref_ids` |
| `00-全局地图.md` 对应小节（如果新增了节） | [V] `check_map_section` |

**铁律**：判点号是稳定主键，能不改就不改。必须改时：
1. 全局搜索旧编号 `grep -rn "旧编号" references/`
2. 逐处替换为新编号
3. 跑 `python scripts/verify.py` 确认无"引用悬空"FAIL

---

## 3. 改元数据（版本号/作者/description）

触发场景：发布新版本、更新描述文案。

| 位置 | 同步规则 |
|---|---|
| `SKILL.md` frontmatter `metadata.version` | 改这里 |
| `skill.json` `"version"` | 必须与上面一致 [V] |
| `SKILL.md` frontmatter `description` | 改这里 |
| `skill.json` `"description"` | 必须与上面同源同文 [V] |
| `SKILL.md` frontmatter `metadata.author` | 改这里 |
| `skill.json` `"author"` | 必须一致 [V] |
| `skill.json` `"updated"` | 改日期（与 frontmatter 不强制一致，WARN 级别） [V] |
| `project_overview/` 中展示的版本 / 日期 | 须同步 `skill.json` [V] `check_project_overview` |
| `docs/assets/badges.svg` 与 `project_overview/assets/badges.svg` | 运行 `python docs/scripts/generate_badges.py` 双端生成 [V] |

**快速操作**：改完 `SKILL.md` frontmatter 后，执行 `python scripts/verify.py`，如有不一致会直接报 FAIL。

---

## 4. 新增一章

触发场景：验收框架需要覆盖一个新的评估面。

| 步骤 | 位置 | 检查 |
|---|---|---|
| 1. 先过扩容三关（通用/公用/可判） | 见 `00-全局地图.md` 头部规则 | [H] 人工判断 |
| 2. 创建 `references/NN-主题词.md` | 新文件 | - |
| 3. 更新 `00-全局地图.md` | 对应小节 | [V] `check_map_section` |
| 4. 更新 `SKILL.md` 路由表 | 加一行链接 | [V] `check_links` |
| 5. 更新 `scripts/verify.py` KNOWN_REF_FILES | 加文件名 | 手动 |
| 6. 全跑 `python scripts/verify.py` | 零 FAIL | 确认通过 |

---

## 5. 删除一章

与新增反向，注意：

| 步骤 | 风险 |
|---|---|
| 从 `references/` 删除文件 | 其他章可能有纯文本引用（"与 X.Y 联动"），会语义悬空 |
| 从 `SKILL.md` 路由表删除 | 链接残留会被 verify 报死链 |
| 从 `00-全局地图.md` 删除小节 | 必须同步，否则 verify 报"地图冗余" |
| 从 `verify.py` KNOWN_REF_FILES 删除 | 不同步会报"缺登记文件" |
| 其他章正文中的跨章引用 | verify 能报"引用判点不存在"，但语义需人工清理 |

---

## 6. 修改 `verify.py` 本身

触发场景：增加新的机械检查项、修复误报。

| 注意事项 |
|---|
| `ROOT = Path(__file__).resolve().parent.parent` — 脚本必须在 `scripts/` 下才指向仓库根 |
| 新增检查函数后，在 `main()` 的逐文件循环里调用 |
| `runtime_targets()` 返回扫描范围：SKILL.md + README.md + references/*.md；docs/ 和 scripts/ 自身不在扫描范围（README 仅参与链接/字符/wikilink 检查，不跑章结构/主题词/地图） |
| 修改 `ALLOW_PUNCT` / `ALLOW_SYMBOLS` 白名单 = 放宽/收紧 R4 符号纪律，需同步 `docs/00-写作与引用规范.md` 第四节 |
| 改完跑自身验证：`python scripts/verify.py` 确认不误报 |

---

## 7. 修改 `project_overview/` 展示页 / 可视化资产

触发场景：改判点、版本、展示页数据、视觉设计或交互。

| 需要联动的位置 | 检查方式 |
|---|---|
| `charts.js` 的十章判点分布、`script.js` 的章节 `pts`、`index.html` 的判点总数 | 与 `references/` 判点表同步 [V] `check_project_overview` |
| `index.html` 中展示的版本与日期 | 与 `skill.json` 同步 [V] `check_project_overview` |
| `docs/assets/` 与 `project_overview/assets/` 的同名 SVG | 运行两个 `docs/scripts/generate_*.py`；双端字节一致 [V] |
| 远程前端依赖 | 固定版本、SRI、anonymous CORS；不引入远程字体 [V] `check_project_overview` |
| 动效和 Tab 交互 | 保留 `prefers-reduced-motion` 与键盘 / ARIA 语义 [V] 基础锚点；[H] 浏览器实测 |

## 9. 常见 FAIL 及修复方法

| verify 报错 | 原因 | 修复 |
|---|---|---|
| `黑名单字符 U+XXXX` | 使用了 emoji/箭头/非白名单符号 | 替换为允许的 ASCII 或文字（见 R4 换算对照） |
| `链接目标不存在` | 文件改名/移动后链接未更新 | 修正链接路径 |
| `链接目标越过 references/` | 技能包正文链向了 `docs/` 或外部文件 | 删除该链接（R1 白名单违规） |
| `正文小节 N.M 未进正文小节导航` | 加了 `## N.M` 但没更新导航行 | 在该章顶部的导航引用行中补上 |
| `文件名主题词与 H1 不一致` | 改了文件名没改 H1 或反之 | 三方对齐（文件名 / H1 / 地图） |
| `引用的判点号 X.Y.Z 不存在` | 删了判点但别处还在引用 | 全局搜该编号，逐处清理或指向替代判点 |
| `正文小节 X.Y 未出现在 00-全局地图.md` | 正文加了小节但地图没登记 | 在地图补登记该小节 |
| `地图小节 X.Y 在正文中不存在` | 地图加了小节但正文没写 | 补正文或删除地图条目 |
| `skill.json 与 frontmatter 不一致` | 改了元数据只动了一边 | 双写同步（通常以 SKILL.md 为准，同步到 skill.json） |
| `project_overview ... 不一致` | 展示页统计 / 元数据未随正文更新 | 按第 7 节同步展示页；SVG 改动后重跑对应生成脚本 |
