**产出结构**（严格按多文件模块拆分）：

- `project_overview/index.html`（骨架，含 3 张内联 SVG 架构图）、`style.css`、`script.js`、`charts.js`、`assets/`（overview.svg + badges.svg 副本）

**关键设计决策**：

- 图表 5 张（Chart.js）：判点分布、五层 SLO、完成率四件套 A/B、两段式阈值、分层评估成本占比
- 判点数据由扫描统计得出：01:23 / 02:68 / 03:41 / 04:39 / 05:30 / 06:29 / 07:38 / 08:39 / 09:34 / 10:16 = **357**；附录 A 为 11 条目（非判点）
- 章节卡、文档索引、目录树均由 script.js 从内置数据对象渲染（数据取自真实扫描，非硬编码 HTML）
- 如实标注已知缺口：无单元测试、无 CI、版本号手动双写、无英文版

**踩坑与修复（可复用）**：
1. headless Chrome `--dump-dom` 下 IntersectionObserver **不触发** → 计数动画停在 0、reveal 元素永久 opacity:0。修复：首屏可见元素直接执行 + 定时兜底（2.5s）+ scroll 时的 sweepReveal() 补显示。
2. `--virtual-time-budget` + rAF 可能被节流 → 计数动画额外加 `setTimeout(dur+260)` 强制写终值。
3. Git Bash 下 node 解析 `/tmp/x` 会变成 `D:\tmp\x`，重定向的临时文件要用绝对 Windows 路径。
4. 无头冒烟测试手法：`chrome.exe --headless=new --disable-gpu --no-sandbox --virtual-time-budget=N --dump-dom file:///...` 再对 DOM 做正则断言（元素数量、计数器终值）。
