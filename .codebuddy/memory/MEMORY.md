## README 写作铁律（2026-09-03 用户定调）
- README 是对外说明文档，不是内部交流稿。行文要正式、信息密度高，不要解释性括注与口语旁白。
- 该有的关键信息必须有：定位、档位体系、技能名、仓库地址、安装方式、文档结构。
- 不同角色读者各配"可直接复制"的开场白；开场白内仓库地址成句写（"技能来源仓库为 <URL>"），不用括号括注。
- 内部代号（R3 / P0 等）与章内指引不进入 README，一律转成对外说法。

## 语言策略（2026-09-03 用户定调）
